# 👑 Admin Cheat Sheet

This is a quick reference for you and your friend to manage the Bingo event!

## 1. Access the Admin Panel
- **Where:** Click the **big jewel at the top** of the main game screen.
- **Password:** Enter the secret password.

## 2. Monitor Players (Leaderboard Tab)
- Watch all players' scores update in real-time.
- **Inspect:** Click on any player in the list to see their exact 4x4 grid and the boxes they checked.
- **Reset:** Use the red "Reset All Scores" button to clear the board and start a brand new game.

## 3. Edit the Game (Manage Challenges Tab)
- Here you can Add new tasks or Delete old ones using the "X".
- *Good to know:* If you change the challenges, existing players keep their current grids. Only new players (or those who click "Play Again") will get the new challenges.
